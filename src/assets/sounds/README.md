# 効果音の録音（差し替え用）

ここに音のファイルを置くと、アプリの合成音の代わりに鳴ります（`src/lib/soundAssets.js`）。
置かなければ合成音のままです。

| ファイル名 | 鳴る場面 |
|---|---|
| `laugh.mp3` | はじめの遊びができたときの笑い声 |
| `boing.mp3` | 押したときの音「ボヨーン」 |
| `creature-dolphin.mp3` など | 押したときの音「生きものの声」（dolphin / whale / turtle / octopus / crab） |

- 形式は mp3 / m4a / aac / wav / ogg。iPad で確実に鳴るのは mp3 か m4a。
- 大きさはアプリ側で効果音の上限に抑えます（測定の合図音より大きくならない）。
- **使ってよい権利のある録音だけ**を置いてください（App Store で配布します）。
