かんたん説明書

ご家族・先生・支援者の方へ。NeuroNode（ニューロノード）のスイッチで「押す」練習を、遊びながらするアプリです。はじめは、いつ押しても必ず何かが起きる遊びから始めます。

1はじめる前に（1回だけ）

  • NeuroNode を iPad にキーボードとしてつなぎます。スイッチを押すと、アプリの遊びが進みます。
  • iPad の「設定」→「アクセシビリティ」→「スイッチコントロール」はオフのままにします。 アプリの黄色い枠で選びます（アプリの中の設定を変える必要はありません）。
  • 音が大事な遊びです。iPad の音量を上げ、消音（マナーモード）を切っておきます。

iPad 本体のスイッチコントロールで操作したいときだけ、iPad とアプリ（支援者の設定の 「スイッチのくわしい設定」→「iPad のスイッチコントロールを使う」）の両方をオンにします。 iPad だけをオンにすると、黄色い枠（アプリ）と iPad の枠が両方出て、うまく選べません。

3遊びの順番（おすすめ）

番号遊びどんな遊び？むずかしさ
①押すと 出てくる押すたびに、真っ暗な画面から生きものが出てきます。いつ押しても大丈夫。はじめは ここから
②ふうせん わり押すたびに、ふうせんが1つずつ割れます。5回で全部割れます。かんたん
③ぬりえ押すたびに、絵に色がついていきます。5回でできあがり。かんたん
④ボールを 打つ転がってくるボールを、押してバットで打ちます。振れば必ず当たり、ぴったりだとホームラン。なれたら
⑤リールを 止める回る絵が、目標の絵になったときに押します（タイミングの練習）。なれたら
⑥高い音だけ高い音のときだけ押し、低い音では待ちます。なれたら
⑦アームで つかむ動くアームが景品の上に来たときに押します。チャレンジ
⑧さかなつり「アタリ」の音（れんしゅうでは大きな「！」も）が出たら、すぐ押します。チャレンジ

①〜③は失敗がありません。「押したら何かが起きる」ことが分かったら、④（振れば必ず当たる、タイミングの入り口）へ。そのあと⑤からのタイミングの遊びへ進みます。

4支援者の設定

遊びを選ぶ画面の右上「支援者の設定」を、指でさわると開きます（スイッチでは開きません。 ご本人が誤って開かないようにしてあり、設定の画面では黄色い枠も止まります）。戻るときは「← ホームへ」です。 変更は自動で保存されます。キーボードでは Tab で移動し、Enter／Space で見出しを開閉します。

「よく使う設定」（最初から出ている6つ）

  • 遊びの雰囲気 … 世界の動きや、押したとき・できたときのお祝いを選びます。
  • 声で読み上げる … 説明やほめ言葉を声で読みます。
  • 効果音 … 押した音や拍手を鳴らします。遊びの合図は切れません。
  • 枠が動く速さ … 次の遊びへ枠が移るまでの時間です。
  • 大きい文字 … 画面の文字を大きくします。
  • 画面をよく見る遊びを隠す … リールとアームをホームから隠します。

くわしい設定（見出しを押すと開きます。いくつでも同時に開けます）

  • スイッチのくわしい設定 … iPad のスイッチコントロールを使う、枠を自動で動かす、枠が動いたときの音、画面に「おす」ボタンを出す
  • 見え方・声のくわしい設定 … 文字づかい、くっきり表示、読み上げの声の大きさ、読み上げの声、タイミングの遊びの絵
  • 遊びごとの難しさ … リールを止める、高い音だけ、アームでつかむ、さかなつりの速さ・回数など（遊びの中の「この遊びの設定」からも変えられます）
  • 音の素材 … 声と効果音の素材の作者と出典
  • 研究（れんしゅう／そくてい） … 研究で測るときだけ使います。ふだんは「れんしゅう」のままさわりません。 「そくてい」の回は、遊びの速さ・回数・手がかりが決まった値に固定されます。押すタイミングの基準をとる手順もここにあります。

くわしい設定には、まとまりごとに「既定に戻す」があります。押すと、何を戻したかがすぐ下に出ます。 灰色で変えられない項目には、その行に理由が出ます（そくていの回は、そくていで使う値も出ます）。

遊びの雰囲気（よく使う設定のいちばん上。4つから選びます）

  • なし … 絵と 押した 手応え。最後は 一言と 星。
  • すっきり … 小さな 粒と 星の 輪。世界の 動きは 止める。
  • にぎやか … いつもの 遊び。けっかで ラッコと キラキラびんが お迎え。
  • おおさわぎ … 押したあとに 星が たまる。最後は パレードと 服の ごほうび。

光や音に敏感な人は「すっきり」か「なし」に。光の点滅は、どの雰囲気でも1秒に3回までです。 そくていの回は、どの雰囲気を選んでいても、遊びに演出を足しません。

5こまったとき

黄色い枠と、iPad の枠が両方出る
iPad の「スイッチコントロール」をオフにしてください（「はじめる前に」を見てください）。
枠が動かない
「スイッチのくわしい設定」→「枠を自動で動かす」をオンにします。「スイッチのくわしい設定」→「iPad のスイッチコントロールを使う」がオンのあいだは、アプリの枠は動きません。
枠が速すぎる・遅すぎる
「よく使う設定」→「枠が動く速さ」で変えます。
画面を見続けるのが難しい
「スイッチのくわしい設定」→「枠が動いたときの音」を「名前を読む」にすると、枠が動くたびに遊びの名前を読みます（「小さな音」は音だけ）。
光や動きがつらそう・興奮しすぎる
「よく使う設定」→「遊びの雰囲気」を「すっきり」か「なし」にします。
音が出ない
iPad の音量と消音（マナーモード）を確かめます。「よく使う設定」→「効果音」もオンにします。
声が出ない・小さい
「よく使う設定」→「声で読み上げる」をオンにします。大きさは「見え方・声のくわしい設定」→「読み上げの声の大きさ」で変えます。
設定が灰色で変えられない
その行に理由が出ています。「そくていの回は固定です」なら、「研究（れんしゅう／そくてい）」→「れんしゅう／そくてい」を「れんしゅう」にすると変えられます。
変えた設定を元に戻したい
くわしい設定の、まとまりごとの「既定に戻す」を押します。
押しても何も起きない
NeuroNode が iPad につながっているか（キーボードとして）を確かめます。画面を指でさわって動くなら、アプリは動いています。

この説明書は、アプリの設定画面の「はじめての方へ：つかいかた」と同じ中身です。
