# スイッチ1つの終了経路（U4）

自前の自動走査で選んだエンドレスは、20秒押さずに待つと、その回を既存のmanual終了として閉じ、「もういちど／おわる」を走査する。もういちどは説明から新しい回を始める。終了はホームへ戻る。説明に待ち方を表示する。

課題中のスイッチは従来どおり即時採時し、課題入力に渡す。長押しのために最初の入力を遅らせる方法は、反応時間や押す意味を変えるため採用しない。途中で一時停止して同じ試行へ戻る方法も時刻を変えるため採用しない。新しい終了理由やconfigを足さず、既存destroyのmanual終了記録を使う（エンドレスはfinished=true・aborted=false・実際の試行数をtargetTrialsへ戻す既存の意味も維持する）。エンドレスは練習専用であり、測定モードではタイマーを作らない。通常回の測定の描画・入力・時刻には手を入れない。

選択が出た時点でタイマーとゲームを閉じる。自前走査はこの選択の2項目だけで再開する。ゲームの設定を開いている間は選択を出さない。終了・結果・再起動時に待ちを解除する。iPad Switch Controlへの委譲では既存の「おわる」を使い、この自前走査用の待ちは作らない。

音の出口が使えず課題を始められない画面は、セッションが始まっていないので、次のスイッチ入力でホームへ戻す。これは測定試行中の入力には当たらない。画面にその戻り方を記す。

20秒の無入力を終了意思と確定せず、選択で本人に決めてもらう。待っているだけで回が中断されるという代償はあるため、対象を自前自動走査のエンドレスだけに限る。記録のfinished・abortedの意味は既存のエンドレスのmanual終了と同じで、新しい終了分類には変えない。
