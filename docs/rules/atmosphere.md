# 遊びの雰囲気（なし・すっきり・にぎやか・おおさわぎ）

支援者の設定「遊びの雰囲気」（保存の値 `settings.fxLevel`、開発名「ドパガキモード」）の4つの段が、どの遊びで
何を出すか。**中身の持ち主はコードの表 `src/lib/atmosphere.js`**。この文書はその読み方で、値を変えるときは表を
直し、ここを合わせる。演出エンジン（`src/lib/fx/`）・舞台（`src/lib/games/partyStage.js`）・ホスト
（`src/lib/games/gameHost.js`）・はじめの遊び（`beginnerKit.js`）・けっか（`results.js`）は、段の名前で分岐せず、
表の欄を読む。

## 段ごとの中身

| 欄 | なし | すっきり | にぎやか（既定） | おおさわぎ |
|---|---|---|---|---|
| 押した手応え（弾み・輪） | 形の変化だけ（動かさない） | ○ | ○ | ○ |
| 起きたことの粒（effects） | なし | 少なく小さく（0.4倍・0.6倍の大きさ） | いつもどおり | 多く（1.5倍）・花火 |
| 世界のゆっくりした動き（worldMotion） | 止める | 止める | 動く | 動く |
| ラッコとキラキラびん（companions） | なし | なし | **けっかにだけ** | 遊んでいる最中も |
| 観客・旗・音楽 | なし | なし | なし | はじめの遊びだけ |
| おいわい（finale） | なし | 星の輪 | 紙吹雪 | 紙吹雪・パレード・花火 |
| できたときの音（finishCue） | チャイム | チャイム＋短い拍手 | 遊びの設定の音 | ＋ファンファーレ |
| ごほうび（reward） | なし | なし | なし | 遊び終えたら服を1つ・その日のびん |
| けっかへ移るまでの待ち（finaleWaitMs、タイミングの遊び） | 0 | 0.65秒 | 1.6秒 | 7.2秒 |
| けっかのお祝いのあいだ、枠を待たせる（resultRevealMs） | 0 | 0 | 1.4秒 | 3.4秒 |

- **にぎやか は既定**（みんなが最初に見るもの）。遊んでいる最中の見え方と音は、雰囲気の仕組みを入れる前と同じ。
- **けっかの主役は、どの段でも遊びの一言と星の評価**（「すごい！ きみは プロだ！」など。クライアントの要望
  `docs/design-renewal-2026-09-25.md` §1.6）。ラッコ・びん・服はその横に足す。
- 声（読み上げ）と効果音の入り切りは、別の設定（声で読み上げる・効果音）が決める。雰囲気は「何が出るか」を決める。
- この遊びの「できたときのおいわい」を「なし」にしてあれば、静かな段（なし・すっきり）でも拍手と「やったー」を足さない。

## 遊びの型ごとの上限（`atmosphereFor(level, kind, { audioCue })`）

- **はじめの遊び**（押すと 出てくる・ふうせん わり・ぬりえ・ボールを うつ）: 表のとおり全部。
- **タイミングの遊び**（リール・高い音だけ・アーム・さかなつり、エンドレスも）: れんしゅうの回だけ。
  - 音楽・観客・旗は出さない（合図の音を聞くこと自体が課題で、押した音も埋もれる。`docs/design-renewal-2026-09-25.md` §3.17）。
  - ラッコとびんは遊ぶ面の外の角に小さく置き、試行のあいだは動かさない。反応は結果が出たあとだけ。置き場の無い
    画面（幅 900px 未満・高さ 400px 未満など）では、遊んでいる最中は出さず、けっかでだけ出す。
  - 合図が音の課題（高い音だけ・さかなつり）では、節目の音（ベル）も鳴らさない（高い音の合図と取り違えうる）。
  - びんの星は、全部成功で 15（いっぱい）。エンドレスは成功1回で星1つ、15個ごとに次のびん。
  - ゲームが言う終わりの声（何回できたか）を、ホストの「やったー」で上書きしない。

## 守る線

- **そくていの回は何も変えない。** 段は none として扱い、舞台も属性も音も足さない。
- **端末の「動きを減らす」（iPad の視差効果を減らす・Windows のアニメーション効果オフ）は見ない**（2026-10-01、
  ユーザーの判断）。演出の量は「遊びの雰囲気」だけで決める。揺れや光が苦手な利用者には、支援者が「なし」か
  「すっきり」を選ぶ。以前は端末の設定で弱め（9/28）、全部止めていた（9/30）。Windows のアニメーション効果が
  オフの PC では、遊んでも何も起きないように見えた。
- **動きを止める段（なし・そくていの回）でも、合図と結果は最後の姿で見せる**（さかなつりの「！」など。`src/decoration-motion.css`）。
- **分からない値は none**（動いている最中）。保存の既定（にぎやか）へ戻すのは `state.js` の sanitize。
- 光と花火は1秒に3回まで（`fx/fxSafety.js` の回数制限）。黄色 #FFC83D は走査の枠だけ。
- おおさわぎの たまるもの（びんの星・服・その日のびん）は研究の記録（`session.summary`・CSV）に入れない。雰囲気そのものは
  `session.config.fxLevel` に残る。
