# 支援者の設定

支援者（家族・先生・療法士）が使う設定画面の決まり。**中身の持ち主はコード**で、ここはその読み方。

| ファイル | 持つもの |
|---|---|
| `src/lib/settingDefinitions.js` | 保存キーごとの名前・説明・範囲・選択肢・値の形・そくていで固定されるか・遊びの中でも変えられるか。設定画面と遊びの中の「この遊びの設定」が共有する正本 |
| `src/lib/settingsFields.js` | 画面の並び（まとまり）・いま変えられない理由・既定に戻すとき何を戻すか |
| `src/lib/supporterGuide.js` | 説明書の中身（設定画面の「はじめての方へ」と、印刷用 `public/guide.html` の両方） |
| `src/lib/state.js` | 保存の形・既定値・読み込みの検査（sanitize）。**研究の記録の一部なので変えない** |
| `src/lib/difficultyMode.js` | そくていの回の値（`MEASUREMENT_PROTOCOL`） |

## 並び

**よく使う設定（いつも見えている7つ）**: 言語 / Language・遊びの雰囲気・声で読み上げる・効果音・枠が動く速さ・
大きい文字・画面をよく見る遊びを隠す。利用者が変わったら確かめたいもの（言葉・感覚・選ぶ余裕・読める大きさ・見て追う力
への配慮）。言語は いちばん上（2026-10-02、ユーザーの判断「言語の選択を よく使う設定に」）。名前は2つの言葉を並べ
（「言語 / Language」）、選択肢はそれぞれの言葉（日本語・English）で書く。どちらの言葉の画面でも見つけて戻せるように。

**くわしい設定（畳んである）**: スイッチ・見え方と声・遊びごとの難しさ（リール・高い音だけ・アーム・さかなつり）・
研究（れんしゅう／そくてい、押すタイミングの基準をとる）・音の素材。

## 決まり

- **項目を足すときは `settingDefinitions.js` に足し、並びは `settingsFields.js` に足す。** 画面に直接書かない。
  範囲は sanitize と同じにする（`tests/settings-definitions.test.mjs` が確かめる）。
- **使えない項目は、理由をその行に字で出す**（そくていの回で固定・iPad のスイッチコントロール中・読み上げがオフ）。
  灰色にするだけにしない。理由は読み上げ（aria-describedby）にも渡す。
- **そくていの回で固定される項目には、実際に使う値を添える**（「そくていでは 3.2秒」）。
- **既定に戻す** は、くわしい設定のまとまりごと。いま変えられない項目と「iPad のスイッチコントロールを使う」は戻さない
  （アプリだけ戻すと枠が2つ出る）。何を戻して何を残したかを、ボタンのすぐ下に出して読み上げる。
- **回の名前は「れんしゅう」「そくてい」**。キャリブレーションは「押すタイミングの基準をとる」。
- **支援者の画面の言葉は、利用者の「言語」に合わせる**（日本語・英語。2026-10-02、ユーザーの判断「言語が変わったら、
  支援者設定の名称も変更されるように」。それまでは日本語だけだった）。設定の画面・遊びの中の「この遊びの設定」・
  入口（「支援者の設定」・タブ・枠の状態の札）・はじめての方への説明が、言語を変えたその場で変わる。文は {ja, en} の組で
  表（`settingDefinitions.js`・`settingsFields.js`・`games/gameSettings.js`）に置き、`src/lib/supporterText.js` の
  `say()` で選ぶ。利用者の世界の辞書（i18n.js。ふりがな・声のパック）には入れない。印刷用の説明書（public/guide.html）は
  日本語のまま。**評価ログ（記録の画面）と書き出しの中身は、まだ日本語**（研究の記録の言葉と合わせるため。変えるなら別に決める）。
  走査は動かさない（タップとキーボード）。
- **書き出しの名前は、書き出す記録の参加者から**（1人ならそのID、2人以上は multi、記録なしは no-id）と日時。
- 測定の条件を変える設定は、禁止せず記録する（`docs/rules/measurement-invariance.md`）。
- **遊びの中の「この遊びの設定」**（`src/lib/games/gameSettings.js`）は、遊んでいる最中にその場で変えるもの。
  はじめの遊びの背景・音・おいわい、タイミングの遊びの速さ・広さ、れんしゅうの回の「絵の かんじ」（えほんみたい／シンプル。
  `settings.practiceArts`、遊びの種類ごと）。絵は遊びの中だけの設定で、支援者の設定画面には置かない
  （2026-10-01、ユーザーの判断「ゲーム内のこの遊びの設定から」）。
