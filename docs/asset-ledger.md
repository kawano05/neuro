# 素材台帳

最終更新：2026-09-23（対象コミット `acef8a9`）

アプリに組み込む絵・音について、出所と利用条件を追えるようにするための台帳。公開時と引継ぎのときの根拠にする（製品版修正設計書 v3.1 §14.5・§18.1）。

## 記入ルール

- 素材を追加・差し替えたら、同じコミットでこの台帳も更新する。
- 生成した素材：ツール、モデル、生成日、プロンプトの要点、原本の保管場所を書く。
- 配布されている素材：配布元のURL、ライセンス名、クレジット表記の要否、確認した日を書く。
- 録音した素材：話者と本人の同意、録音日、加工の内容を書く。
- 分からない欄は「未確認」と書く。推測で埋めない。

## 新しい素材の条件

- **画像**：背景を透過したPNGにする。四隅は透明、輪郭はアンチエイリアスを残す。`tests/art-quality.test.mjs` が確認しているのはアームとリールだけなので、新しい画像もこのテストの対象に加える。
- **容量**：PWAは全素材を事前にキャッシュする。既存素材は1枚おおむね20KB以下に抑えている（魚釣り5枚で46KB、アーム5枚で69KB）。
- **絵柄**：既存の絵柄（フラット塗り、太い焦げ茶の輪郭、白のハイライト）と、C案の絵柄のどちらに揃えるかを先に決める。
- **音**：iOSで再生できる形式（AAC または MP3）にし、素材ごとに音量を揃える。
