# 遊びの雰囲気「おおさわぎ」（2026-09-29）

## 1. 何か

支援者の設定「見え方・音」の **遊びの雰囲気** を、次の4つにした。値は演出の強さ（`settings.fxLevel`）のまま。

| 画面の名前 | fxLevel | 中身 |
|---|---|---|
| なし | none | 粒・揺れ・紙吹雪を出さない |
| すっきり | subtle | 押した手応えと、できたときの小さなお祝い |
| にぎやか（既定） | normal | これまでの「ふつう」 |
| おおさわぎ | big | これまでの「はで」に加えて、下の2章のものが全部出る |

新しい設定を足さずに fxLevel に乗せたのは、`session.config.fxLevel` が CSV まで残っているから。どの雰囲気で遊んだかが、研究の記録からそのまま分かる。

## 2. おおさわぎの中身（押すと 出てくる）

押すたびに次のものが重なっていく。出てくる動物と、押したときの音はいつもと同じ。

- **なかま**：ラッコが一緒に遊ぶ。押すたびに跳ねて、手をたたいて、3回目からは回る。5回目は2倍の大きさになって真ん中へ出てくる。
- **音楽**：遊び始めると静かなマリンバが流れる。押すたびに楽器が重なり（キック→ベース→4つ打ちと手拍子→ハイハット→きらきら→和音→盛り上げ→旋律→シンバル）、速くなる（114→128 BPM）。最後の1回で2半音上がる。声が出るあいだは音楽を下げる。
- **キラキラ**：画面の上の数が 100 → 1,500 → 2まん → 30まん → 500まん と増える。1まん・10まん・100まんを越えるたびに、ハンコとベルと声でお祝いする。最後はボーナスで2倍の1000まんになる。
- **観客**：2回目から魚が集まって跳ねる。3回目で旗が張られる。5回目は、動物と魚のパレードと花火。
- **ごほうび**：遊び終えるたびに、ラッコの服が1つもらえる（ぼうし→リボン→おうかん）。次からは着て出てくる。けっかには、キラキラ・その日の合計・もらった服が出る。

キラキラは点数ではない。何回遊んでも、押せば同じ数になる。失敗が無い遊びなので、数は「すごさ」の手ざわりとして使う。

背景は、押すと 出てくる の設定「遊ぶ画面の背景」で **海**（既定）・暗い・明るいから選ぶ。「黒い画面から絵が出る」形（暗い）は残した。見えにくさのある子には、黒い地のほうが絵を見つけやすいことがある。海の上では、動物に白いふちを付ける（クジラの青とイルカの水色が海と近い）。

## 3. 守る線（どの雰囲気でも同じ）

- **光**：やわらかい光と花火を合わせて数え、どの1秒をとっても3回まで（`fx/fxSafety.js` の `createBrightLimiter`）。花火は0.4秒より詰めない。以前は光だけを数えていて、フィナーレで光と花火4発（0.25秒おき）が重なると、1秒に5回の明るい出来事になっていた。
- **入れないもの**：画面全体をパッと光らせる演出、色がぐるぐる変わる背景、放射線（集中線）の背景。発作の恐れがあるため、参考にしたドリルにあっても入れない。
- **黄色は走査の枠だけ**：おおさわぎの粒・ハンコ・旗・服には黄色を使わない。
- **けっかの枠**：おおさわぎのけっかでは、お祝い（数え上げ・ラッコ・ごほうび・花火）が終わるまで枠を動かさない（`PARTY_RESULT_SCAN_DELAY_MS`）。紙吹雪の下で枠を進めない。
- **音**：音楽は効果音と同じ出口を通り、効果音を切れば鳴らない。音楽は音が合図にならない遊び（はじめの遊び）だけで鳴らす。合図のある遊びで鳴らすと、測定そのものが変わる。
- **動きを減らす**：端末で「動きを減らす」が入っていれば、演出の強さは「すっきり」までになる（`resolveFxLevel`）。おおさわぎにはならない。

## 4. 参考にしたもの

算数ドリル「ドパドリル」（https://github.com/grmchn/dopa-drill 、コードは MIT License）の、解くたびに演出と音楽が重なっていく作りを参考にした。

- 参考にした考え方：一緒に喜ぶキャラクター、段階的に楽器が重なる音楽と最後の転調、桁が増えていく数と節目のお祝い、観客とパレード、遊ぶともらえる着せかえ。
- 使っていないもの：キャラクター「ドパキチ」と名前・ロゴ（MIT の対象外で、商用利用には作者の許可が要る）。ラッコと、曲のコード進行・旋律は、このアプリで作った。
- 音楽の「段ごとに楽器を足す条件」は、ドパドリルの `app/js/audio.js` を元に書いた。MIT の著作権表示と許諾文を `src/lib/partyMusic.js` の頭に入れてある（MIT の条件）。

## 5. 作り

| ファイル | 役目 |
|---|---|
| `src/lib/party.js` | 決まり（数・節目・音楽の段・服・その日の合計）。DOM に触れない |
| `src/lib/partyMusic.js` | 音楽（Web Audio の合成。段・調・速さ・声のあいだ下げる） |
| `src/lib/art/partyArt.js` | ラッコ・魚・旗・海の背景の絵（SVG の文字列） |
| `src/lib/games/partyStage.js` | 遊びの画面に重ねる舞台と、けっかの見せ方 |
| `src/lib/games/colorLegacy.js` | 押すと 出てくる。雰囲気が big のとき partyStage を重ねる |
| `src/lib/games/gameHost.js` | 服とその日の合計の保存（`state.party`）、けっかの枠を待たせる |
| `src/lib/fx/*` | ハートの粒、おおさわぎの演出、光と花火をまとめて数える回数制限 |

保存：`state.party = { day, sparkles, outfits }`。研究の記録ではないので、記録を消しても残す。

声：新しい文は `scripts/voice/lines.mjs` に足し、`generate.py` で声のパックへ入れた（日本語 VOICEVOX:四国めたん、英語 Kokoro-82M）。すでにある声は作り直していない。

## 6. 確かめ方

- `node tests/party.test.mjs`：数・節目・服・その日の合計・光と花火の回数制限
- `tests/web-smoke.mjs` の「plays the party atmosphere」：ラッコ・キラキラ・観客・旗・けっか・枠の待ち・保存
- 実機では、音楽の大きさ（声より小さく聞こえるか）と、ラッコの動きの速さを見る
