# 文書の地図

どこに何が書いてあるか。**決まり（rules/）は今の約束**で、仕事のたびに読み、変えたら直す。
**報告（reports/）はその日の記録**で、あとから書き換えない（古くなった所は、今の決まりの文書を見る）。

## まず読むもの

| 文書 | 中身 |
|---|---|
| `../README.md` | アプリの概要・動かし方・検査の回し方 |
| `../basic-design.md` / `../detailed-design.md` | 研究の設計（測定の手順・判定・記録）。研究の記録の意味はここが正 |
| `overall-design-2026-09-28.md` | 全体設計: 押したら、世界が応える。ごほうびの文法・安全の決まり・測定との境界 |
| `design-renewal-2026-09-25.md` | デザイン改修（はっきりした色）の要望と判断の記録。巡ごとの判断の理由（§3）と残っていること（§6） |
